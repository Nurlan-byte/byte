# Экономика пилота: расчётные сценарии

Это **рамка для интервью**, а не измеренный эффект BakePlan. Для Cloud Game Zone пока нет подтверждённых цен, себестоимости, утраченных продаж, времени владельца или фактических заказов. Синтетический CSV не даёт таких величин. Все денежные результаты остаются пустыми до сверки с владельцем и пилотом.

## Какие числа нужны

Для каждого товара `i` и периода `d` запрашиваем у владельца цену `Pᵢ`, закупочную себестоимость `Cᵢ`, фактический остаток и случаи отсутствия товара в часы работы. Для процесса заказа нужны минуты владельца до/после, частота заказов и, если владелец хочет оценить труд в деньгах, согласованная стоимость часа `V`. Отдельно фиксируем срок поставки, кратность упаковки и порог максимального заказа. Нельзя получать утраченный спрос из одного нулевого вечернего остатка.

| Вопрос | Формула после сбора данных | Что означает |
|---|---|---|
| Деньги в запасе | `Σᵢ средний остатокᵢ × Cᵢ` | Капитал, занятый товаром; снижение запаса не равно прибыли. |
| Вечерняя недополученная выручка | `Σᵢ подтверждённые неудовлетворённые штукиᵢ × Pᵢ` | Верхняя оценка выручки при наличии товара, без учёта замены покупки другим товаром. |
| Возможная валовая маржа | `Σᵢ возвращённые продажиᵢ × (Pᵢ − Cᵢ)` | Требует доказанных возвращённых продаж, а не только прогноза. |
| Время на заказ | `число заказов × (минуты до − минуты после) / 60` | Сэкономленные часы, если замерены обе процедуры. |
| Условная стоимость времени | `сэкономленные часы × V` | Сценарная оценка, только при согласованной ставке. |

## Два сценария для обсуждения

| Сценарий | Допущение | Вывод |
|---|---|---|
| Консервативный | Пока нет замеров, улучшение наличия, запаса и времени принимается равным 0. | Сценарный расчёт даёт **0**; фактический эффект неизвестен, пилот нужен для измерения. |
| Базовый условный | После интервью подставляются подтверждённые `Pᵢ`, `Cᵢ`, упаковки и замеренные в пилоте изменения неудовлетворённых продаж, среднего запаса и времени. | Потенциал = возвращённая валовая маржа + согласованная стоимость времени; изменение капитала в запасе показывается отдельно, без сложения с прибылью. |

Сравнивать нужно одинаковые дни недели и часы работы до/после с учётом праздников, сезонности, акций и изменения цен. Пилот должен вести журнал недоступности товара и ручных замен заказа. Если продажи выросли, но не подтверждено, что это вызвано лучшей доступностью, эффект BakePlan не доказан. Стоимость внедрения и подписки также нужно вычесть, когда она станет известна; платные ресурсы сейчас не предполагаются.
