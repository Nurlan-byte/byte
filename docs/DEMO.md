# Демонстрация примерно за 90 секунд

Только синтетические данные `fixtures/synthetic_demo.csv`, созданные для проекта: пять изделий, 56 календарных дней, никаких исходников реальной пекарни. Не называть этот файл реальными продажами и не показывать синтетический MAE как точность продукта.

## Подготовка до записи

- Чистый запуск по README, отдельная демонстрационная SQLite. Убедиться в `/api/health` и записать commit.
- Нажать «Демо», импортировать с source `synthetic`, bakery `demo`, происхождением «Синтетическая демонстрация BakePlan».
- Для согласованного двухдневного горизонта: дата плана/прогноза `2026-10-13`, срез `2026-10-11`. Для сегодняшней записи после 13 октября это явно историческое воспроизведение.
- Обучить модель заранее: дождаться статуса и проверить каждый товар. Если модель не готова, показать честный B1 и причину, не менять подпись на ML.
- Рассчитать план, проверить допустимые партии. Заранее проверить экспорт, перезагрузку и рестарт на той же БД. Не выдавать этот чек-лист за выполненную ручную QA.

## Сценарий

| Время | Экран и слова |
|---|---|
| 0–12 с | «Небольшой пекарне нужно решить, сколько испечь завтра. BakePlan помогает подготовить план по пяти изделиям, а решение остаётся у владельца». |
| 12–27 с | Импорт синтетического CSV, диагностика. «Проверяем баланс, формат и дубликаты. Пропуск не становится нулём». |
| 27–43 с | Уже подготовленная модель и расчёт. «Прогноз использует только доступные завершённые дни. Показываем фактический метод по товару; при нехватке модели явно используем B1». |
| 43–58 с | Изменить пшеничный хлеб на 84; показать партию 12 и максимум 96. «Прогноз, допустимая рекомендация и моя корректировка различаются». |
| 58–72 с | Подтвердить, открыть историю, экспортировать CSV. «Решение сохранено с версией данных и параметрами; после рестарта остаётся в SQLite». |
| 72–82 с | Вернуться к методу/оценке, показать общий горизонт и N. «B1 и ML сравниваются на одинаковых датах. Готовность модели не доказывает преимущество». |
| 82–90 с | «Данные здесь вымышленные. Реальную точность и экономию ещё проверим с пекарней. Каталог фиксирован, общую загрузку печи проверяет человек». |

Резервный короткий эпизод: импорт `fixtures/invalid_balance.csv` должен показать понятный отказ целиком. В записи не показывать пароль, private-файлы или реальные персональные/коммерческие сведения. Готовность публичного URL и доступ с телефона отмечать только после фактической проверки целевого хостинга.
