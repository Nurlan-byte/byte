# BakePlan — материалы для показа

## Команда и задача

BakePlan помогает владельцу небольшой точки выбрать количество выпечки или готовых товаров на следующий день и сохранить принятое решение. Для Cloud Game Zone показан **полностью синтетический** сценарий закупки бара; цены, спрос, остатки и другие параметры в нём предварительные и требуют интервью с владельцем. Текущий состав: Нурлан — модель, API, интерфейс, демо; Асыл — клиент, данные, презентация. История прежних вкладов — в [CONTRIBUTING](../CONTRIBUTING.md).

- Локальная беззвучная запись синтетической закупки создаётся командой `npx playwright test video/cgz-capture.spec.ts --config=playwright.video.config.ts` (Windows: `npx.cmd`). Перед показом проверьте `capture_status: complete`, `source_dirty: false`, SHA текущего checkout и длительность 90–120 секунд. Запись не опубликована в репозитории.

## Запуск за 5 минут на Windows

Из чистого checkout выполните команды из корня репозитория:

```powershell
py -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r backend/requirements.lock
npm.cmd --prefix frontend ci
$env:BAKEPLAN_DB = "$PWD\data\bakeplan.sqlite3"
.\.venv\Scripts\python.exe -m uvicorn backend.app:app --host 127.0.0.1 --port 8000
```

В другом терминале:

```powershell
npm.cmd --prefix frontend run dev
```

Откройте `http://127.0.0.1:5173`. Для синтетического сценария клуба выберите режим закупки и следуйте [инструкции](CLOUD_GAME_ZONE.md). Используйте отдельную локальную БД и не загружайте CSV в рабочую среду.

## Что работает и что ещё не доказано

Работают локальный импорт по контракту `procurement-1`, расчёт B1/ML с fallback, ручное подтверждение, история и экспорт заказа. Синтетический replay воспроизводит этот поток в отдельной SQLite. Числа и команды проверок приведены в [VERIFICATION](../VERIFICATION.md).

Остаются непроверенными реальный эффект для клуба, фактические цены и упаковки, доступность товара в течение дня и экономия времени владельца. Синтетический сценарий не является доказательством точности прогноза на реальных продажах. [Экономическая рамка](ECONOMICS.md) задаёт формулы и измерения для пилота без выдуманной выгоды.
