# Cloud Game Zone: синтетический сценарий бара

Cloud Game Zone — компьютерный клуб с баром в Шымкенте; город подтвердил владелец 17.10.2026. Рабочие условия, ассортимент, упаковки и цены ещё требуют проверки. **Все записи этого сценария синтетические.** Они смоделированы по предварительным допущениям, не являются кассовой историей, накладными или цитатами владельца. Частные исходные файлы здесь не использованы и не опубликованы.

Руководитель Cloud Game Zone разрешил опубликовать фрагмент своего отзыва: «до этого закупали админстраторы как чувствуют … посмотрим на результаты» (руководитель Cloud Game Zone, Шымкент). Он сообщил об использовании BakePlan во всех четырёх филиалах; это сообщение владельца, а не независимо проверенное развёртывание или измеренный эффект. В отзыве нет подтверждённых чисел экономии, продаж или списаний для расчёта выгоды.

## Что можно заменить после интервью

Единственный файл параметров — [`fixtures/cloud_game_zone_synthetic_config.json`](../fixtures/cloud_game_zone_synthetic_config.json). В нём предварительные названия 6 барных товаров, базовый спрос, сезонность по дням недели, размеры упаковок, максимумы поставщика, пороги пополнения, шум и редкие модельные дефициты. Ни упаковки, ни цены, ни реальные продажи не подтверждены владельцем. После интервью измените этот JSON одним отдельным коммитом, затем пересоздайте фикстуры и повторите проверки. Не подменяйте синтетические строки ранее предоставленной таблицей.

```powershell
.\.venv\Scripts\python.exe -m scripts.generate_cgz_synthetic
.\.venv\Scripts\python.exe -m scripts.generate_cgz_synthetic --check
```

Фиксированный seed `20261017` создаёт [`CSV procurement-1`](../fixtures/cloud_game_zone_synthetic.csv) и [`каталог JSON`](../fixtures/cloud_game_zone_synthetic_catalog.json): 91 день с 16.07 по 14.10.2026, 6 SKU, 546 строк. Даты/товары уникальны, `opening + received = sold + waste + closing`, междневный остаток непрерывен. Пятница и выходные в формуле спроса сильнее обычных дней, есть шум и 5 явных модельных дефицитов. Поля `is_open` и `stockout_status` относятся к вымышленному сценарию; нулевой остаток в иных данных сам по себе не доказывает дефицит. `received` — поступление готового товара, не выпечка. Контракт: [PROCUREMENT](PROCUREMENT.md).

## Проверенный маршрут демонстрации

Прямой API replay в **новой локальной SQLite**, без внешней базы:

```powershell
.\.venv\Scripts\python.exe -m scripts.replay_cgz_synthetic --output-dir test-results\cgz-synthetic-replay
```

Каталог результата должен отсутствовать до запуска; скрипт откажется его перезаписать. В нём появятся `replay.json`, `confirmed-order.csv` и тестовая SQLite. Для ручного показа в UI выберите режим **Закупка**, загрузите CSV и внесите шесть позиций каталога из JSON, указав источник **synthetic** и явное происхождение «Синтетический сценарий Cloud Game Zone». Затем откройте качество прогноза, обучите на срезе 14.10.2026, выберите пятницу 16.10.2026 с тем же срезом, укажите сценарный срок поставки 1 день и пригодный остаток 0 для всех товаров. Это историческое воспроизведение, а не реальный заказ на сегодня. Измените предложенное количество воды с 24 на 36, подтвердите, проверьте историю и CSV экспорт.

Последний локальный replay на SHA CSV `a0ecee1cf940d16372d7e1f2a0fde07daf4d88792a14db95f714c8cb967f2944` прошёл весь маршрут: импорт 546 строк, модель `ready`, прогноз t−2, упаковки, ручное изменение, подтверждение (revision 1), история и экспорт. Фактический метод для пятницы: `ML` для колы, энергетика и холодного чая; `B1` для воды, чипсов и шоколадного батончика (`product_not_ready` по внутреннему отбору). Это демонстрирует честный fallback, не обещание превосходства ML. Точные числа по каждому SKU и SHA экспорта сохраняет `replay.json`.

Цены, потери выручки, время владельца, реальная доступность товара и экономический результат пока не наблюдались. Прогноз относится к наблюдаемым продажам синтетики; будущую точность на клубе этот сценарий не проверяет.
