## Контракт прогноза и заказа

Для прогноза, создания и подтверждения заказа и сверки выданных прогнозов с продажами источником типов служат маршруты FastAPI. При изменении запроса или ответа обновите серверную схему и выполните команды из корня проекта в Python-окружении BakePlan с установленными зависимостями.

```sh
npm --prefix frontend ci
python -m tools.order_api
npm --prefix frontend run typecheck
```

Включите обновлённый `frontend/src/generated/order-api.d.ts` в тот же коммит. CI выполняет `python -m tools.order_api --check` и обнаруживает устаревшие типы. Для генерации достаточно локального кода. [Генератор](tools/order_api.py) · [Настройки проверки](.github/workflows/ci.yml)

## Стабилизация и приёмка

Для продуктового улучшения заранее выберите цель из [плана продукта](PRODUCT_PLAN.md). По итогам добавьте в его журнал значения до и после, тип данных, доказательство и вывод по каждому из четырёх критериев. Если полевых наблюдений ещё нет, техническую проверку и ожидаемый эффект укажите раздельно.

Технический результат проверяется на точном commit и через CI. Windows проверяет обычный запуск, браузерный поток и API restart; Linux — snapshot/restore и изолированный Docker demo. Linux-only операции не считаются проверенными на Windows. Фактическая ручная проверка, публичное размещение и независимый будущий ML-эксперимент фиксируются отдельно.

До freeze не расширяем ассортимент, семейства моделей или продуктовые подсистемы. Изменение партии/лимита в UI и экономическая оптимизация сейчас не реализованы; не обещать их в демонстрации.
