# Работа команды

Текущий состав: Нурлан — модель, API, интерфейс, демо; Асыл — клиент, данные, презентация.

История прежнего распределения вкладов: Нурлан — Python, модель, API и хранение; Бага — интерфейс; Диас — независимая проверка и воспроизведение запуска; Асыл — источник данных, разрешение на использование и границы продукта. Это не текущий состав команды.

Это стартовый код, созданный с помощью Codex; распределение ролей не приписывает авторство автоматически созданным изменениям. Коммиты создаются в реальное время с отдельной атрибуцией Codex. Не публикуйте реальные CSV, секреты, базы SQLite или документы пекарни.

Меняйте API и интерфейс вместе. Перед PR выполните проверки из [журнала проверок](VERIFICATION.md#повторение-проверок). Используйте отдельные ветки, PR в draft до независимого просмотра. Не заменяйте проверку на более слабую ради зелёного CI. Изменения методики требуют новой версии конфигурации и проверок временного среза.


## Стабилизация и приёмка

Технический результат проверяется на точном commit и через CI. Windows проверяет обычный запуск, браузерный поток и API restart; Linux — snapshot/restore и изолированный Docker demo. Linux-only операции не считаются проверенными на Windows. Фактическая ручная проверка, публичное размещение и независимый будущий ML-эксперимент фиксируются отдельно.

До freeze не расширяем ассортимент, семейства моделей или продуктовые подсистемы. Изменение партии/лимита в UI и экономическая оптимизация сейчас не реализованы; не обещать их в демонстрации.
