# Работа команды

Нурлан: Python, модель, API и хранение. Бага: интерфейс. Диас: независимая проверка и воспроизведение запуска. Асыл: источник данных, разрешение на использование и границы продукта.

Это стартовый код, созданный с помощью Codex; роли выше — дальнейшая ответственность команды, а не приписывание авторства автоматически созданным изменениям. Коммиты создаются в реальное время с отдельной атрибуцией Codex. Не публикуйте реальные CSV, секреты, базы SQLite или документы пекарни.

Меняйте API и интерфейс вместе. Перед PR выполните проверки из README. Используйте отдельные ветки, PR в draft до независимого просмотра. Не заменяйте проверку на более слабую ради зелёного CI. Изменения методики требуют новой версии конфигурации и проверок временного среза.
