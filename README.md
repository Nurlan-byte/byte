<h1 align="center">BakePlan</h1>

<p align="center">План выпуска и закупок на следующий день для малого бизнеса.</p>

BakePlan помогает владельцам пекарен, компьютерных клубов и небольших торговых точек решать, сколько товара приготовить или заказать.

Приложение превращает историю продаж в понятный план: показывает прогноз, учитывает остатки, размеры партий и упаковок, предлагает количество. Владелец проверяет рекомендацию, при необходимости меняет её и подтверждает решение.

- **Для пекарни:** план выпечки с учётом партий и ограничений выпуска.
- **Для клуба или магазина:** заказ готовых товаров у поставщика.
- **Для владельца:** сохранённые планы, история решений и экспорт в CSV.

Публичный пример закупки бара Cloud Game Zone использует полностью синтетические данные. Он показывает работу приложения; точность на реальных продажах и экономический эффект ещё предстоит проверить.
