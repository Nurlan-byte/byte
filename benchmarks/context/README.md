# Проверка влияния календаря и погоды на прогноз

Проверили, помогает ли контекст заранее предсказывать число чеков с напитком и число поездок. Каждый прогноз строился за два дня. Одни и те же товары и даты прошли через базовый B1, прежнюю модель BakePlan, модель с календарём, модель с календарём и погодой и текущий автоматический выбор. Последний сравнивает B1, Ridge по истории и Ridge с контекстом для каждого товара на отложенных датах, доступных к обучению. Все варианты BakePlan используют штатное обучение, прогноз и переход на B1 по результатам внутренней проверки. Обучение повторялось каждые семь дней. Ошибка (MAE) измерена по внешнему периоду, который на дату каждого решения ещё не наступил.

| Источник и период проверки | Пар | B1 | Прежняя модель | С календарём | С календарём и погодой | Автовыбор |
|---|---:|---:|---:|---:|---:|---:|
| Три кафе Сурабаи, 06.08–30.09.2025, чеков с вариантом напитка на точку в день | 1 008 | 0,7669 | 0,7129 | 0,7145 | 0,7157 | 0,7133 |
| Велопрокат Сеула, 01.09–30.11.2018, поездок по городу в сутки | 80 | 5 418,65 | 5 274,29 | 5 242,67 | 5 090,23 | 5 078,04 |

В кафе подключение календаря и погоды повысило ошибку на 0,38% относительно прежней модели. Автовыбор сократил разницу до +0,05% и улучшил результат в двух филиалах из трёх. Для 217 из 1 008 прогнозов он выбрал Ridge с контекстом, для 721 — Ridge по истории, для 70 — B1. В Сеуле ошибка с автовыбором снизилась на 3,72%. Из 80 прогнозов в 34 выбран контекст.

Правило выбора добавили после изучения первого сравнения на этих периодах. Каждый выбор использует только свою более раннюю проверку, но для независимой оценки итогового решения нужен новый период. Для компьютерного клуба требуется такая же проверка по филиалам, включая дни похолодания. [Результаты по точкам и число переходов на B1](results.json)

## Входные данные

- **Кафе.** В реальных данных Engel, Gaol, Kurniawan и Budiharto три заведения в одном городе и 53 820 чеков. Выбрали по шесть вариантов кофе или чая, наиболее частых до 4 августа 2025 года. В день с чеками отсутствие варианта после его появления учитывается как ноль. Считаем чеки, в которых упомянут напиток. Количество порций и наличие товара неизвестны. Каждый прогноз прежней модели сверяется с уже опубликованным прогнозом для этого филиала, напитка и даты. [Набор Mendeley v2, CC BY 4.0](https://doi.org/10.17632/kcgf45y24m.2) · [Статья авторов о точках в Сурабае](https://doi.org/10.1016/j.dib.2026.112519) · [Прежнее сравнение](../open-sales/results/cafe/forecasts.csv)
- **Погода в Сурабае.** Для трёх точек использована одна сетка NOAA GFS вблизи центра города (−7,25°, 112,75°). Агрегировали 6 528 почасовых прогнозов Open-Meteo в 272 значения средней температуры и суммы осадков. Для каждого часа взят прогноз с упреждением 72 часа. Добавили сутки на выпуск и доставку, поэтому итог за день T доступен к концу T−2. Файл содержит рассчитанные суточные показатели. [Архив Open-Meteo](https://open-meteo.com/en/docs/previous-runs-api) · [Атрибуция и условия](https://open-meteo.com/en/terms) · [Снимок](surabaya_gfs.csv)
- **Календари.** Для Индонезии использованы национальные праздники и опубликованные дни коллективного отдыха. Изменение на 18 августа вступает в расчёт только после публикации 7 августа. Режим работы конкретного кафе определяется по его чекам. Для Сеула взят национальный календарь с переносами и июньскими выборами. Первоначальные календари опубликованы до прогнозного периода. [Первоначальный календарь Индонезии](https://setkab.go.id/pemerintah-tetapkan-hari-libur-nasional-dan-cuti-bersama-tahun-2025/) · [Поправка от 7 августа](https://www.kemenkopmk.go.id/pemerintah-tetapkan-cuti-bersama-18-agustus-2025-untuk-peringatan-hut-ke-80-ri) · [Корейский астрономический институт, календарь на 2018 год](https://www.kasi.re.kr/kor/publication/post/newsMaterial/5971?cPage=33)
- **Сеул.** Набор Sathishkumar V. Easwaramoorthy содержит 8 760 почасовых записей. В периоде проверки учитываем 80 из 91 суток, когда прокат работал все 24 часа. Погодные измерения доступны модели начиная со следующего дня. Здесь проверяется ценность недавней погоды, включая изменение температуры. Фактическая погода в день будущей поездки недоступна модели. [UCI Seoul Bike Sharing Demand, CC BY 4.0](https://doi.org/10.24432/C5F62R)

## Как повторить

Из корня репозитория используйте окружение Python проекта. Сохраните ZIP UCI и два исходных файла Mendeley (`Products.csv`, `Transactions.csv`) в выбранные папки. Команда сверяет контрольные суммы источников и показатели из таблицы. Можно указать только один набор. Флаг `--predictions` сохраняет фактический спрос, прогнозы и даты срезов для независимого пересчёта. [Скачать ZIP UCI](https://archive.ics.uci.edu/static/public/560/seoul+bike+sharing+demand.zip) · [Скачать файлы Mendeley](https://data.mendeley.com/datasets/kcgf45y24m/2)

```powershell
python benchmarks/context/evaluate.py --cafe private/cafe-source --seoul private/seoul.zip --check --predictions private/context-predictions.csv
```

Проверка суточного снимка погоды повторно запрашивает архив по фиксированным координатам, датам, модели и упреждению.

```powershell
python benchmarks/context/sources.py
```
