# BakePlan — речь на два минуты

**Асыл, слайды 1–3.** Каждый день пекарня решает, сколько выпустить завтра, а клуб — сколько готовой продукции закупить. Обычно это решение живёт в голове одного человека. Руководитель Cloud Game Zone в Шымкенте описал прежний подход так: «до этого закупали администраторы как чувствуют». BakePlan превращает ежедневный выбор в понятный план: прогноз по товарам, учёт упаковок и лимитов, ручное утверждение, история решений и экспорт. Это уже работающий процесс и для выпуска в пекарне, и для закупки в клубе.

**Нурлан, слайды 4–5.** Здесь настоящий экран BakePlan. Данные на нём синтетические: 91 день и шесть товаров, чтобы публично показать работу интерфейса. Владелец видит предложения по всем шести товарам и может их изменить: для воды система предложила 24 штуки, а владелец утвердил 36. AI применяется после проверки на прошлых датах. В этом демо он выбран для трёх товаров из шести, для остальных остаётся базовый расчёт B1. Мы не выдаём результат демо за доказательство точности на реальном спросе.

**Асыл, слайды 6–8.** У нас есть первый клиентский контакт — Cloud Game Zone. По словам руководителя, BakePlan используют четыре филиала в Шымкенте; это его сообщение, а не независимо подтверждённые показатели эффекта. Следующий этап — двухнедельный замер: остатки, случаи дефицита и время администраторов до и после применения. Только после этого можно говорить о выгоде в тенге. Если результат подтвердится, следующий город для проверки — Тараз. Меньше интуиции — больше выручки: эту цель нужно подтвердить цифрами пилота. Мы просим согласовать доступ к данным и пилот. Нурлан отвечает за продукт и код, я — за клиента и презентацию.

## Короткие ответы для жюри

**Есть реальные данные Cloud Game Zone?** Предоставленный файл хранится отдельно и содержит исходные метки строк. Публичный экран показан на синтетических данных. Отдельный тест импорта не подтверждает точность на реальном спросе или экономический эффект.

**Почему AI только для 3 из 6?** Это выбор метода после проверки на прошлых датах в конкретном синтетическом демо. Если AI не проходит проверку, работает базовый B1. Для реальных продаж метод и результат нужно оценить отдельно.

**Что уже работает?** Импорт истории, расчёт выпуска и закупки, упаковки и лимиты, предложения, ручное утверждение, история и экспорт CSV. Решение остаётся за владельцем.

**Почему Шымкент и Тараз?** Cloud Game Zone находится в Шымкенте. Тараз — предлагаемый следующий город для проверки после результата пилота, а не объявленное развёртывание.

**Сколько денег экономит?** Подтверждённой суммы пока нет. Для неё нужны реальные закупочные цены, продажи, списания и замеры времени за сопоставимые периоды.

**Чем лучше Excel?** Система связывает данные, расчёт, правила упаковки и утверждённое решение в одном процессе. Практическую выгоду проверим в пилоте.
