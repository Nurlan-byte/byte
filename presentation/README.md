# Презентация BakePlan

[PDF питча](BakePlan_pitch.pdf) содержит 12 слайдов. [Версия для браузера](index.html) открывается офлайн. Между слайдами можно переходить стрелками и пробелом. [Текст выступления](SPEECH.md) рассчитан на двух участников.

[Демонстрация продукта](BakePlan-demo.webm) длится 1 минуту 36 секунд. Это непрерывная запись синтетического сценария из [проверки GitHub Actions](https://github.com/Nurlan-byte/byte/actions/runs/45017864794) для коммита `e1c8861d88f512aecf59cf443069612e3d48ec15`. Кадр подтверждённого заказа на слайде взят из этой записи. Сценарий позволяет увидеть импорт, прогноз, решение о количестве и выгрузку CSV.

Для сборки выполните `python presentation/build.py`, затем `node presentation/render.mjs`. Первая команда встраивает утверждённый логотип и снимок экрана в HTML. Вторая экспортирует PDF и проверяет навигацию и размещение содержимого в разрешениях 1920×1080 и 1366×768.

Цена, размер доступного рынка и продажи в первый год представляют сценарий команды. Оценка рынка опирается на открытый каталог клубов Казахстана. Проверка спроса и цены предусмотрена в плане пилотов.
