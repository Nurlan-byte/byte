# BakePlan — презентация для жюри

Откройте `index.html` двойным щелчком: логотип и скриншот встроены, подключение к сети не требуется. Навигация: ←, →, пробел. `BakePlan_pitch.pdf` — версия для отправки, `SPEECH.md` — речь и ответы на вопросы.

Исходник утверждённого логотипа v2 — `assets/BakePlan-v2-logo.svg`, получен из Library `libfile_40b354fe98b08191bcfba75c5dcd42a4`; SHA-256 `00b21166a05cb2dbe7898a1cfca1e49e7bc5d6f18dd6526e6f4eb7fa9ab7eafc`.

`screenshots/cgz-six-confirmed.png` — снимок реального UI в Chromium с viewport 1920×1250 и deviceScaleFactor 2. Он получен на открытом синтетическом CSV и каталоге Cloud Game Zone в отдельной временной SQLite. На снимке заказ на 16.10.2026: вода предложена 24 шт., изменена владельцем на 36 шт. и подтверждена. DOM, API и текст не подменялись. Для слайда 4 из этого PNG составлены только обрезанные фрагменты строк. Исходный файл Cloud Game Zone в презентацию не включён.

Сборка: `python presentation/build.py`, затем `node presentation/render.mjs`. Первый шаг создаёт самодостаточный `index.html` из `index.template.html` и локальных артефактов. Второй сохраняет PDF, проверяет офлайн-запросы и переходы по клавишам, а также создаёт временные PNG всех слайдов в игнорируемой папке `qa/`.

Факты и границы: цитата сокращена и исправлена редакционно. Четыре филиала — только со слов руководителя. Число 3/6 относится к смоделированному демо. Денежный эффект пока не заявлен; двухнедельный пилот — следующий планируемый шаг.

На слайде 4 показана композиция реальных фрагментов экрана из `screenshots/cgz-six-confirmed.png`: шесть товаров, их упаковки, методы, предложенные и утверждённые количества. Повторяющиеся пояснения между ними обрезаны; содержание фрагментов не изменено.
