# BakePlan pitch

Откройте `index.html` двойным щелчком: снимок экрана встроен в файл, соседние папки для показа не нужны. Навигация: ←, →, пробел. Внешние шрифты, скрипты и сетевые запросы не используются. `BakePlan_pitch.pdf` — версия для отправки; `SPEECH.md` — речь и ответы на вопросы.

`screenshots/cgz-order-1920x1080.png` снят Playwright с реального UI на коде `33272f4afec2112acd65ba5ea077b76826d475fe`. Для захвата использовались открытые синтетические CSV/каталог Cloud Game Zone и новая временная SQLite через `playwright.video.config.ts`. На экране предложение воды 24 шт. вручную изменено на 36 шт.; заказ ещё не подтверждён. DOM, API и текст интерфейса не подменялись. Исходный файл Cloud Game Zone в презентацию не включён.

Повторный рендер: `node presentation/render.mjs`. Скрипт сохраняет PDF и временные скриншоты восьми слайдов в игнорируемой папке `qa/`, а также проверяет офлайн-запросы и навигацию. Проверка PDF: восемь объектов страниц, `MediaBox [0 0 1440 810]` (16:9), размер 95 952 байта на момент подготовки.

## Редакционные решения

- Цитата сохранена дословно с исходным написанием «админстраторы».
- На слайде 2 написано «Риск пустой полки»: время фактического дефицита не подтверждено.
- Четыре филиала указаны только «со слов руководителя»; эффект в ₸ не заявлен.
- Две недели реальных продаж на слайде 8 обозначены как план.
- Формулировки брифа на слайдах 2 и 4 дают более 20 слов при подсчёте всех видимых строк, включая цитату, атрибуцию и примечания. Они сохранены ради точности и обязательной маркировки смоделированных данных.
