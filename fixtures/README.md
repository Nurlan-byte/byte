# Только синтетические тестовые данные

`synthetic_demo.csv` создан программно для проверки продукта: 56 календарных дней, пять товаров, единица — штука. Это не история пекарни, не качество модели, не экономия. Копия `frontend/public/demo.csv` даёт быстрый пример в интерфейсе.

Для воспроизводимого расчёта: target_date `2026-10-12`, cutoff `2026-10-11`, B1. У p1 понедельники имеют продажи 10,20,…,80; B0=80, B1=65. Партия 12, максимум100 разрешают не более96. Расчёт прошлой даты помечается историческим воспроизведением.

`invalid_balance.csv` намеренно нарушает баланс на одну штуку и должен отклоняться целиком. Настоящие исходники и база SQLite не входят в Git.

`synthetic_sales_lines.csv` — полностью искусственные транзакционные строки01.01–09.03.2017 для отдельного sales-only CLI. Число строк не обозначает физические штуки. Этот формат не является operational DailyActual и не импортируется в API производственного плана.


Для актуального двухдневного ML-демо используйте дату `2026-10-13` и срез `2026-10-11`; ранний пример выше сохранён как численная B0/B1-регрессия. Данные синтетические и предназначены для открытого показа программы. Они не содержат наблюдений пекарни или стороннего датасета. Все дополнительные тестовые истории генерируются внутри тестов; реальные источники не включены.
